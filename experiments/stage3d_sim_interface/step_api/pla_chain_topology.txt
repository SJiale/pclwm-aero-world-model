[5] 单点替换可行性
  方案：把 Model Source4 替换为 Inport 或 Signal Builder
  
  优点：
    - 只需替换 1 个模块（28 个 Model Source 中的 1 个）
    - PLA 信号链路清晰：Lookup -> Bus Creator1 port 1
    - 下游不需改动
  
  风险：
    - Model Source4 的输出数据类型/采样时间需匹配
    - T-MATS 内可能有隐藏依赖
  
  验证方法：
    1. 检查 Model Source4 的输出端口数据类型
    2. 在模型副本中替换为 Inport
    3. 用 SimulationInput.setExternalInput 驱动
    4. 验证与旧方法数值一致
