[6] 关键判断
  PLA 输入链路:
    Model Source4 (Mask: T_vec_M=MWS.In.t_PLA, input_array_M=MWS.In.PLA)
      -> Input_profiles (1-D Lookup, InputValues=T_vec_M, Table=input_array_M)
      -> Bus Creator -> 控制/执行机构
  Mask 值是【字符串表达式】，指向 base 工作区变量 MWS
  Simulation 对象在 initialize() 时解析一次并缓存
  后续 setBlockParameter/mask 更新不会触发重新求值
