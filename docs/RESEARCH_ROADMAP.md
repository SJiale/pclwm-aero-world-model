## 四、★ 2026-11-05 优先任务

### 任务 1：补齐基线（P0）

#### 1.1 LSTM（正常工况）

**目的**：确认 GRU 不是特例。若 LSTM 与 GRU 性能相当，说明"RNN 类模型都行"；
若 LSTM 明显不同，需分析原因。

| 项 | 设定 |
|---|---|
| 架构 | 标准 LSTM，hidden=128，与 GRU-h128 同容量 |
| 训练 | 相同数据划分、WINDOW=32、HORIZON=32、60 epoch、seed=0 |
| 评价 | 相同统一评价器 |

**预期输出**：test_id / test_ood / 长时 60s / 逐通道 / 参数量

#### 1.2 Mask-LSTM（传感器重构）

**目的**：传感器重构中的第二个 RNN 对照。

| 项 | 设定 |
|---|---|
| 架构 | Mask-aware LSTM，hidden=128，与 MaskGRU 同容量 |
| 输入 | `[obs_masked, mask, act]` |
| 状态更新 | LSTM cell（复用 h 和 c）|
| 训练 | 相同缺失增强（固定/随机/突发）|

**预期输出**：三种推理模式（开环/分段/逐步）× 四场景

#### 1.3 T45→T4 线性回归（关键对照）

**目的**：**验证 Mask-RSSM 的优势是否只是学到了 T45 的线性映射。**

若线性回归就能达到 22.39 °R，那 Mask-RSSM 的价值需要重新审视。

| 项 | 设定 |
|---|---|
| 输入 | T45(t)、T45(t-1)、...（可选滞后阶数）|
| 输出 | T4(t) |
| 拟合 | 最小二乘，只用 train |
| 评价 | 与 Mask-RSSM 相同的场景与评价区间 |

**关键指标**：永久失效 @20s 的 RMSE。若接近 22.39，说明 RSSM 只是做线性插值。

#### 1.4 T45→T4 MLP

**目的**：非线性对照。

| 项 | 设定 |
|---|---|
| 架构 | MLP，2 层 128，输入 T45 历史（可选 WINDOW 步）|
| 训练 | 相同预算 |
| 评价 | 相同场景 |

**关键**：若 MLP 显著优于线性回归但仍差于 Mask-RSSM，说明 RSSM 有额外价值。

### 任务 2：潜空间可解释性（P0）

#### 2.1 目标

**冻结现有 RSSM（MaskRSSM v3），分析其潜状态编码了什么物理信息。**

#### 2.2 提取的表示

| 表示 | 维度 | 说明 |
|---|---|---|
| **h** | 128 | 确定性状态（GRU 递推）|
| **z** | 32×32 → 1024 | 离散随机状态（one-hot）|
| **z_argmax** | 32 | 每维取 argmax（类别索引）|
| **[h, z]** | 1152 | 拼接 |

#### 2.3 Linear Probe 设计

**对每个表示 × 每个物理量，训练线性回归（闭式解）：**

| 物理量 | 说明 | 是否派生 |
|---|---|---|
| T4 | 观测通道 | 否 |
| T45 | 观测通道 | 否 |
| P36 | 观测通道 | 否 |
| N2int | 观测通道 | 否 |
| Wfact | 观测通道 | 否 |
| **OPR** | P36 / P2 | 派生 |
| **T4/T45** | 温度比 | 派生 |
| **ΔT** | T4 − T45 | 派生 |

**指标**：R²（训练集上）、RMSE（物理单位）

**关键问题**：
1. h 和 z 各自编码了什么？
2. z 是否编码了比 h 更细/更粗的信息？
3. 物理派生量（OPR 等）是否能被线性解码？

#### 2.4 对比实验：T4 缺失时的信息变化

| 条件 | 分析 |
|---|---|
| 全部传感器正常 | 基线 probe 精度 |
| T4 缺失 | h/z 中的 T4 信息如何变化？ |
| T45 也缺失 | T4 信息是否进一步丢失？ |

**核心问题**：RSSM 在 T4 缺失时，是否把"其他传感器推断的 T4"编码进了 h/z？

**方法**：
1. 在正常轨迹上训练 probe
2. 在 T4 缺失的推理过程中提取 h/z
3. 用 probe 解码 T4，与模型 Decoder 输出对比

#### 2.5 时间尺度分析（可选）

**若时间允许**：
- 分析 h 各维度的时间常数（ACF）
- 分析 z 各维度的切换频率
- 对比 DT-K1 的 h_fast vs h_slow 的差异

## 八、风险与诚实声明

### 8.1 最大风险：**Mask-RSSM 的优势可能是平凡的**

**如果 T45→T4 的线性回归就能达到 22.39 °R**，那么：
- Mask-RSSM 没有学到"动力学"，只学到了"T45 是 T4 的下游"
- 论文的核心贡献受到挑战

**明天的 1.3 和 1.4 任务就是检验这个风险。**

### 8.2 其他风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 数据线性度高（R²=0.999994）| 复杂模型无发挥空间 | 需更有激励性的数据 |
| 测试集太小 | 结论不稳健 | 需扩展 |
| KL 项失效 | RSSM 的先验未受约束 | 需修复 |
| 单训练种子 | 无法判断训练稳定性 | 需多种子 |

### 8.3 诚实声明

**本项目至今发生了 3 次结论反转**（都由 bug 导致）：
1. "RSSM 崩溃" → 是 Gumbel/Argmax 不一致
2. "Mask-GRU 全面更好" → 是重建监督错误
3. "RSSM 更善于利用传感器" → 是敏感度指标错误

**这意味着：任何新结论都必须先排除实现缺陷，再讨论算法优劣。**

**明天的任务设计已考虑这一点**：先用简单基线（线性/MLP）划出"平凡解"的下限，再看复杂模型是否真的超出。
