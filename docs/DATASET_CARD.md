## 3. 字段定义

### 3.1 观测字段（`data.csv`，38 列）

单位说明：**AGTF30e 使用英制单位**。

| 列名 | 物理含义 | 单位 | 状态 |
|---|---|---|---|
| `time_s` | 仿真时间 | s | [核验] |
| `S0_W` | 进气道流量 | **lb/s** | [核验] 量级 336–2263 |
| `S0_Tt` | 进气道总温 | **°R** | [核验] 418–556 |
| `S0_Pt` | 进气道总压 | **psia** | [核验] 4.66–18.74 |
| `S0_FAR` | 进气道油气比 | — | [核验] 恒 0 |
| `S0_ht` | 总焓 | BTU/lbm **[未核验]** | — |
| `S2_*` | 风扇出口 | 同上 | [核验] |
| `S25_*` | 增压级(LPC)出口 | 同上 | [核验] |
| `S36_*` | 高压压气机(HPC)出口 | 同上 | [核验] Tt 1010–1647 °R |
| `S36_Ps` / `S36_Ts` | 该截面的静压/静温 | psia / °R | [核验] |
| `S4_*` | 燃烧室出口 | 同上 | [核验] Tt 1800–3266 °R |
| `S45_*` | 高压涡轮出口 | 同上 | [核验] Tt 1231–2307 °R |
| `S5_*` | 低压涡轮出口 | 同上 | [核验] Tt 897–1450 °R |

**单位换算**：
- °R → K：`K = R × 5/9`
- psia → kPa：`kPa = psia × 6.89476`
- lb/s → kg/s：`kg/s = lb/s × 0.453592`

**温度序物理自检 [核验]**：30 条轨迹全部满足 `S4_Tt > S36_Tt`、`S4_Tt > S45_Tt`、`S45_Tt > S5_Tt`。

### 3.2 动作字段（`action.csv`，3 列）

| 列名 | 物理含义 | 单位 | 状态 |
|---|---|---|---|
| `time_s` | 仿真时间 | s | [核验] |
| `Wfact_lb_s` | **实际燃油流量** | **lb/s** | [核验] 0.122–1.687 |
| `Wfdmd_lb_s` | **燃油指令（控制器输出）** | **lb/s** | [核验] |

**关键区分**（实验方案 MD §3 要求）：
- **`Wfact` = 实际燃油**，来自 `out_Dyn.act.Wfact`，经过作动器动态
- **`Wfdmd` = 燃油指令**，来自 `out_Dyn.cntrl.Dmd.Wfdmd`，控制器直接输出
- 两者差异最大约 0.03 lb/s（约 2%），说明**作动器有短暂动态**

**当前训练使用的是 `Wfact_lb_s`**（实际燃油）。理由：它是真正进入燃烧室的燃油，物理上是状态转移的真实输入。
**未做** `Wfdmd` vs `Wfact` 的对照实验（实验方案 MD §3 要求确认两者是否可等同）。

### 3.3 训练用张量（`data/prepared2/data.npz`）

| 键 | 形状 | 说明 |
|---|---|---|
| `{run_id}_obs` | (8001, 16) | 16 个观测通道，**降采样后为 (1143, 16)** |
| `{run_id}_act` | (8001, 1) | 燃油流量 |
| `{run_id}_time` | (8001,) | 时间 |
| `obs_cols` | (16,) | 通道名 |
| `act_cols` | (1,) | `['Wfact_lb_s']` |
| `run_ids` | (30,) | 轨迹 ID |

**16 个训练用观测通道**（从 38 列中选取）：
```
S0_W, S0_Tt, S0_Pt,
S2_Tt, S2_Pt,
S36_Tt, S36_Pt, S36_Ts, S36_Ps,
S4_Tt, S4_Pt, S4_FAR,
S45_Tt, S45_Pt,

```

**降采样**：`step=7`，即每 7 个原始点取 1 个 → **dt_eff = 0.105 s**，
每条轨迹 1143 点（120 s）。

## 5. 归一化参数

**从 train 集拟合**（`z = (x - o_mu) / o_sd`），未存成独立文件，
但可由代码复现：

```python
tr_obs = concat([runs[r]["obs"] for r in splits["train"]])
o_mu = tr_obs.mean(0)      # (16,)
o_sd = tr_obs.std(0)+1e-8  # (16,)
```

**[核验]** 归一化在 `prepare2.py` 与 `train_v2.py` 中均用 train 集，
未用 val/test 信息。但**未持久化为文件**，接手者需从 `data.npz` 重新计算。

**评估时剔除的 5 个通道**（`DROP`）：

| 通道 | 原因 | 证据 |
|---|---|---|
| `S4_FAR` | std 极小(0.0056)，跨工况差异导致相对误差放大 40× | [核验] 逐通道误差表 |
| `S0_Tt` | **轨迹内 std = 0**（进气道温度恒定）| [核验] 方差分解 |
| `S0_Pt` | 同上（若 Alt/MN 固定则恒定）| [核验] |
| `S2_Tt` | 风扇出口温度在慢车点几乎不变 | [核验] |
| `S2_Pt` | 同上 | [核验] |

**这 5 个通道仍参与训练**（Encoder/Decoder 是 16 维），**只在评估指标中剔除**。

## 6. 清洗与剔除规则

| 步骤 | 规则 | 结果 |
|---|---|---|
| 1. 完整性 | 轨迹必须 `time_s` 末值 ≥ 100 s | 剔除 2 条 6 s 的（dataset1 的 r06/r10）|
| 2. 长度 | 点数 ≥ 5000 | 同上 |
| 3. 物理有效性 | 温度序 `S4>S36`、`S4>S45`、`S45>S5` 全程成立 | 30/30 通过 |
| 4. 数值有限 | 关键通道无 NaN/Inf | 30/30 通过 |
| 5. 范围 | `T4 ∈ [200, 4000] °R`，`Pt36 ≤ 800 psia` | 30/30 通过 |
| 6. 仿真状态 | `SIM OK` 且非 `SIM FAIL` | `down` 系列 6 条剔除 |

**未做**：
- 未做去重（30 条轨迹的输入激励与工况组合均不同）
- 未做异常点检测（如离群值剔除）
- 未做重采样以外的平滑

## 7. 数据质量已知问题

| 问题 | 严重性 | 证据 | 影响 |
|---|---|---|---|
| **轨迹数少**（train 15 条）| 🔴 高 | [核验] | GRU 仍有 1.5× 泛化差距；RSSM 可能欠拟合 |
| **test 含工况外推** | 🟡 中 | 见 §4 | 泛化数字包含外推成分，非纯插值 |
| **单一 PLA 激励族** | 🟡 中 | [核验] 只有 5 种波形 | 不能声称「响应任意输入」|
| **无隐藏退化参数** | 🔴 高 | [核验] 30 条全用标称 `s_Eff` | **无法做实验方案 MD 的 B 组** |
| **采样间隔偏细** | 🟢 低 | 0.015s → 0.105s | 已降采样，可接受 |
| **未持久化归一化参数** | 🟡 中 | [核验] | 复现需重算 |
| **down 工况缺失** | 🟡 中 | [核验] 0 条 | 缺少减速动态样本 |
