### 1.4 ⚠️ 实现中的关键约束（踩坑记录）

**失败 4 次后的正确做法**：

| # | 错误做法 | 报错 | 原因 |
|---|---|---|---|
| 1 | 只改 StartTime/StopTime | 状态不连续 | 缺 SaveFinalState/LoadInitialState |
| 2 | 加 SaveFinalState 但用新 Setup | "无法加载完整工作点" | 模型签名不匹配 |
| 3 | 用 ModelOperatingPoint | "停止时间 ≤ 初始工作点时间" | 工作点带时间戳 |
| 4 | 改 xSteady.time=0 | 同上 | 工作点时间是只读的 |

**✅ 正确方案**：

```matlab
% 1. 只建一次 MWS，时间轴覆盖 0 到 T_steady + T_run
t_full = (0:TS:T_steady+T_run)';
MWS = Setup_Simulation(...);   % 仅此一次
assignin('base','MWS',MWS);

% 2. 稳态建立：0 -> T_steady
set_param(MDL,'SaveFinalState','on','FinalStateName','xSteady');
set_param(MDL,'StartTime','0','StopTime',num2str(T_steady));
sim(MDL);

% 3. 后续仿真：从 T_steady 开始（不重建 MWS）
set_param(MDL,'LoadInitialState','on','InitialState','xSteady');
set_param(MDL,'StartTime',num2str(T_steady));
set_param(MDL,'StopTime',num2str(T_steady+T_run));
sim(MDL);
```

**关键点**：
1. **不能重建 MWS**（否则签名不匹配）
2. **新仿真的 StartTime 必须 ≥ 稳态时刻**
3. 稳态状态本身是时间无关的，但 Simulink 的工作点机制要求时间轴连续

### 3.5 覆盖度结论（诚实评估）

**✅ test_ctrl 的优势**：
1. **填补了训练集的"中间态动作"空白**（3 条，\|ΔPLA\|max 1.6–2.5 deg）
2. **动作更平滑**（max 2.488 vs 训练集 30.0）
3. **3/6 条使用新工况**
4. **动作模式不重叠**（正弦/三角/随机/双向阶跃/混合 vs step/aprbs/msin/ramp）

**⚠️ test_ctrl 的局限**：
1. **PLA 均值集中在 55**（54.97±0.13），而训练集覆盖 52–78
2. **PLA 范围窄**（[48, 62] vs 训练集 [40, 80]）
3. 只有 6 条，统计意义有限

**综合判断**：
> **test_ctrl 是合格的"控制导向独立验证集"，但不是"全工况覆盖集"。**
> **它的价值在于：验证代理模型在"MPC 典型动作"（小幅、连续、中间态）上的泛化能力。**
> **不能用它代表发动机全包线性能。**
