### 3.2 连续潜状态递推（只初始化一次，之后完全自主）

| 模型 | 10 s | 30 s | 60 s |
|---|---|---|---|
| RSSM-d128 | 0.1125 | 0.1656 | 0.0984 |
| **RSSM-wide** | **0.0174** | 0.1431 | **0.0483** |

| DT-K8 | 0.0760 | 0.2068 | 0.1061 |
| DT-K4-matched | 0.0902 | 0.1217 | 0.0587 |

### 3.3 判读

**DT-K1 的分段 60s（0.0607）比基线（0.0985）好 38%，但不能归因于时间尺度分离：**
- RSSM-wide（同容量，无时间尺度结构）分段 60s = 0.1195，并未改善
- DT-K1 vs RSSM-wide 的短期性能几乎相同（0.0944 vs 0.0932）
- **说明分段递推的改善更可能来自双 GRU 的状态表达，而非时间尺度机制**

**RSSM-wide 的连续 60s（0.0483）最好，但 10s（0.0174）与 30s（0.1431）波动极大：**
- 说明**单种子结果不稳定**，不能据此下结论
- 连续递推的方差远大于分段递推

## 5. 关键 bug 修复记录

**连续递推误差计算存在 NumPy 广播 bug（已修复）：**

```python
# 错误代码（bug）
pred = rssm.dec(...)              # [1, C]
gt = o[start+k:start+k+1][None]   # [1, 1, C]
errs.append((pred - gt).numpy()[0])   # 广播成 [1, C]，再取 [0] 仍是 [1, C]

# 后续
E = np.stack(errs, 0)             # [n, 1, C]
ps = np.sqrt((E**2).mean(axis=1)) # [n, C]  <- 逐通道，不是标量！
final = ps[-1] / ref              # 变成"最后一个通道的误差"
```

**后果**：连续递推误差被低估 7 倍（如 RSSM-d128 记录 0.0128，实际 0.0984）。

**修复**：
```python
diff = (pred - gt[:, 0]).cpu().numpy()[0]   # 显式 [C]
assert diff.shape == (C_O,)
E = np.stack(errs, 0)                        # [n, C]
ps = np.sqrt((E**2).mean(axis=1))            # [n] 标量
```

**所有正式结果已用修复后代码重算（`results_v2_fixed.json`）。**
**`results_v2.json` 中的 `long_continuous` 字段已废弃，不得引用。**

## 6. 结论（严格区分事实与假设）

### ✅ 实验事实

1. 原始 RSSM-d128 短期预测最好（test_id 0.0898）
2. 固定 K 的 DT-RSSM 短期性能随 K 增大单调退化（K1 0.0944 → K8 0.1162）
3. 同容量对照 RSSM-wide（1.49M）短期（0.0932）与 DT-K1（0.0944）几乎相同
4. DT-K1 分段 60s（0.0607）优于基线（0.0985）
5. 连续递推的方差远大于分段递推（RSSM-wide: 0.0174→0.1431→0.0483）
6. T4/T45 通道误差最大（0.12），是 P36 的 1.8 倍

### ❌ 不支持的研究假设

1. **"双时间尺度分离能提升短期预测"** —— 数据不支持，K 越大越差
2. **"DT 的结构优势来自时间尺度机制"** —— 同容量对照 RSSM-wide 无此结构，短期性能相近
3. **"K=4 是合理的工程初值"** —— K=4 明显差于 K=1

### ⚠️ 不能得出的结论

1. **不能说"DT-RSSM 优于原始 RSSM"** —— 短期预测上原始 RSSM 更好
2. **不能说"K=1 最好说明时间尺度机制有微弱作用"** —— K=1 本质是两路并行 GRU，不构成时间尺度分离
3. **不能把单种子结果当作统计显著结论** —— 需要多种子重复

### 🔶 需要进一步验证

1. **多种子重复**（当前只有 seed=0）
2. **K 与训练轮数的交互**（60 epoch 可能不足以让慢状态学好）
3. **可学习时间尺度门控**（替代固定 K）
4. **连续递推的稳定性**（当前方差过大，需要分析原因）
