# PSVA 失败根因诊断

> 日期：2026-11-06
> 目的：解释为何"监督 h 的前/后 64 维"没有产生功能分化
> **纯分析，无训练**

---

## 一、三个决定性测试

### 测试 A：GRU 权重结构（跨块/块内比值）

从 PSVA 检查点提取 `GRUCell.weight_hh`（形状 [384, 128]，3 个 gate × 128 维），按 `h[:64]` / `h[64:]` 分块：

| Gate | ff (f→f) | fs (s→f) | sf (f→s) | ss (s→s) | **跨块/块内** |
|---|---|---|---|---|---|
| reset(r) | 0.0415 | 0.0422 | 0.0421 | 0.0415 | **1.015** |
| update(z) | 0.0542 | 0.0542 | 0.0559 | 0.0535 | **1.021** |
| new(n) | 0.0477 | 0.0465 | 0.0458 | 0.0463 | **0.982** |
| **平均** | | | | | **1.006** |

**判读**：跨块权重与块内权重**完全同量级**（比值 1.006 ≈ 1.0）。

**没有任何块对角结构**——`h[:64]` 的更新会用到 `h[64:]` 的全部信息，反之亦然。

### 测试 B：功能耦合（扰动泄漏比）

固定 z 和动作，只扰动 `h[:64]`，测量 `h[64:]` 的下一步变化量：

| δ | 扰动fast→fast | 扰动fast→slow | 扰动slow→fast | 扰动slow→slow | **泄漏比** |
|---|---|---|---|---|---|
| 0.1 | 0.0509 | 0.0104 | 0.0087 | 0.0482 | 0.193 |
| 0.5 | 0.2615 | 0.0508 | 0.0445 | 0.2424 | 0.189 |
| 1.0 | 0.5400 | 0.0974 | 0.0896 | 0.4884 | 0.182 |
| **2.0** | 1.1367 | 0.1712 | 0.1704 | 0.9864 | **0.161** |

**泄漏比定义**：`跨块影响 / (跨块 + 本块)`
- 0 = 完全隔离
- 0.5 = 完全耦合

**判读**：泄漏比 0.16–0.19。**跨块影响是本块影响的 20% 左右**——不是完全隔离。

### 测试 C：子空间重叠（真实数据）

用 500 个窗口提取 h，计算 `h[:64]` 与 `h[64:]` 的关系：

| 指标 | 值 |
|---|---|
| corr(h_f 均值, h_s 均值) | **−0.4695** |
| **第一典型相关（CCA）** | **1.0000** |

**判读**：均值负相关（−0.47，说明有一定互补性），但 **CCA = 1.0** 表明**两个子空间完全共线**——存在一个线性组合使二者完全对应。

## 二、为什么失败

### 2.1 机制

```
h_t = GRUCell([z_{t-1}, a_t], h_{t-1})
```

**GRUCell 的每一次更新，输出 h_t 的每一维都依赖 h_{t-1} 的全部 128 维。**

所以：

- `h_f[:64]` 的更新 → 读取 `h_s[64:]` 的信息
- `h_s[64:]` 的更新 → 读取 `h_f[:64]` 的信息

**只监督不同切片，无法阻断这种信息流。**

### 2.2 后果

| 现象 | 解释 |
|---|---|
| Separation 仅 +0.0026 | 切分没产生功能分化 |
| `h_s` 对 Ndot 的 R²（0.9022）> `h_f`（0.8931）| 两者编码的信息几乎相同 |
| 训练损失全面更高 | 切分削弱了每个头的输入信息 |
| 长时推演退化（C8 后段 −14.4%）| 切分让模型"半瞎"，但又要它做长期预测 |

---

## 三、结论

> **PSVA 的失败是结构性的，不是调参问题。**
>
> 要提高快慢分离度，**必须改结构**（分组 GRU / 独立 cell），
> 而不是继续调整 λ、维度分配或监督目标。

**这也解释了为什么调 λ 或换 32/96 分配不会有用**——它们都不改变信息流。

## 四、对研究主线的影响

### 4.1 PSVA 失败**不影响**的内容

| 内容 | 状态 |
|---|---|
| PC-RSSM E3 的 5 种子结果（60s +3.76%，p=0.070）| ✅ 不受影响 |
| E3 短期 OOD +3.45%（p=0.002）| ✅ 不受影响 |
| 所有已归档的实验结果 | ✅ 不受影响 |
| 论文主线（物理锚定改善长期预测）| ✅ 不受影响 |

**PSVA 是一个探索性分支，失败了不代表主线有问题。**

### 4.2 PSVA 失败**提供了**什么

**一个有价值的负面结果：**

> **"仅靠监督不同潜状态切片，无法让共享 GRU 产生快慢功能分化。"**

**这个结论本身可以写进论文**——它解释了"为什么简单的表征分离不够"，为后续是否需要结构改动提供了依据。
