## 一、基线补齐（4 个模型）

### 1.1 LSTM（正常工况）

**文件**：`experiments/baselines/lstm.py`

**架构**：
```python
self.inp = Sequential(Linear(C_obs+C_act, H), LayerNorm(H), SiLU())
self.lstm = nn.LSTM(H, H, num_layers=1, batch_first=True)
self.cell = nn.LSTMCell(H, H)        # ← 未来递推（与训练一致）
self.o2h = Linear(C_obs+C_act, H)
self.dec = Sequential(Linear(H, M), SiLU(), Linear(M, M), SiLU(), Linear(M, C_obs))
```

**关键约束**（吸取 MaskGRU v2 的教训）：
- 训练 forward 与在线 step **必须共用同一个 cell**
- 提供统一 `update(h, c, obs, act)` 原语
- 单元测试：forward vs online_step 的 max diff 必须 < 1e-6

**训练**：与 GRU-h128 完全相同（60 epoch，patience 15，bs 64，lr 1e-3，seed 0）

**评价**：test_id / test_ood / 逐通道 / 长时 60s（分段 + 连续）

**预期**：若 LSTM ≈ GRU（0.0766），说明 RNN 类都行，GRU 不是特例。

```python
self.cell = nn.LSTMCell(H, H)              # 统一更新

self.dec = ...
```

**统一原语**：
```python
def enc_hist(self, obs, mask, act) -> (h, c)
def update(self, h, c, obs_prev, mask_prev, act_prev) -> (o_hat, h, c)
def online_init(...) / online_step(...) / rollout_open(...)
```

**训练**：与 MaskGRU 相同（缺失增强 20/25/25/30%）

**评价**：三模式（开环/分段/逐步）× 四场景

**预期**：若 Mask-LSTM ≈ MaskGRU（33.13），说明 GRU 的重构缺陷是 RNN 通病；
若 Mask-LSTM 接近 MaskRSSM（22.39），说明是 GRU 特有的问题。

### 1.3 T45→T4 线性回归（★ 最重要）

**文件**：`experiments/simple_baselines/linear_t45_to_t4.py`

**目的**：**划出"平凡解"的下限。**

若线性回归就达到 22.39 °R，Mask-RSSM 没有学到动力学。

**设计**：

```python
# 输入：T45 的历史（滞后 0..L-1 步）
# 输出：T4(t)
# 拟合：最小二乘，只用 train 17 条

def build():
    X, Y = [], []
    for rid in train:
        o = norm_obs(rid)
        for t in range(L, len(o)):
            x = [o[t-k, I_T45] for k in range(L)]
            X.append(x); Y.append(o[t, I_T4])
    W = lstsq(X, Y)     # 闭式解
```

**滞后阶数扫描**：L ∈ {1, 2, 4, 8, 16, 32}

**评价场景**：与 Mask-RSSM 完全相同的 4 场景 + 评价区间

**关键比较**：
| 模型 | 永久失效 RMSE | 说明 |
|---|---|---|
| T45→T4 线性 | ? | **若 ≈22.39，Mask-RSSM 无额外价值** |
| MaskRSSM 逐步 | 22.39 | |
| MaskGRU 逐步 | 33.13 | |

**注意**：线性回归**没有**"故障前历史"的概念，它是逐点映射。
为公平，应实现两个变体：
- **无状态**：`T4(t) = f(T45(t))` —— 只有当前 T45
- **有状态**：`T4(t) = f(T45(t), T45(t-1), ..., T4(t-1), ...)` —— 自回归

后者更接近 MaskRSSM 的能力。

## 二、潜空间可解释性（Linear Probe）

### 2.1 目标

**冻结 MaskRSSM v3（`checkpoints_v3/MaskRSSM.pt`），分析 h 和 z 的物理信息。**

### 2.2 提取表示

| 表示 | 维度 | 提取方式 |
|---|---|---|
| h | 128 | `state["h"]` |
| z_onehot | 1024 | `state["z"].reshape(B, -1)` |
| z_argmax | 32 | `state["z"].argmax(-1)` |
| h+z | 1152 | concat |

### 2.3 Probe 设计

**对每个表示 × 每个目标，训练线性回归（闭式解）：**

```python
def linear_probe(X, Y):
    """X [N,D], Y [N] -> R², RMSE"""
    Xm, Xs = X.mean(0), X.std(0)+1e-8
    Xn = (X - Xm) / Xs
    W = lstsq(c_[Xn, 1], (Y - Y.mean())/Y.std())
    pred = c_[Xn, 1] @ W
    r2 = 1 - ((pred - Yn)**2).sum() / ((Yn - Yn.mean())**2).sum()
    return r2, rmse
```

**目标变量**：

| 目标 | 类型 | 说明 |
|---|---|---|
| T4 | 观测量 | |
| T45 | 观测量 | |
| P36 | 观测量 | |
| N2int | 观测量 | |
| Wfact | 观测量 | |
| **OPR** | 派生 | `P36 / P2`（P2 从 aux 取或重算）|
| **T4/T45** | 派生 | 温度比 |
| **ΔT = T4−T45** | 派生 | 温差 |

### 2.4 分析维度

**问题 1：h vs z 的分工**

| 表示 | 预期 R²(T4) | 若...则说明 |
|---|---|---|
| h | ? | h 编码了慢变的物理状态 |
| z | ? | z 编码了快变/离散的模式 |
| h+z | ? | 两者互补 |

**问题 2：物理派生量能否被线性解码？**
- 若 OPR 的 R² 高，说明潜空间学到了"压比"这一物理概念
- 若温度比的 R² 低，说明只学到了原始传感器

**问题 3：T4 缺失时的信息变化**

| 条件 | Probe R²(T4) | 说明 |
|---|---|---|
| 全部正常 | ? | 基线 |
| T4 缺失 | ? | 信息损失多少 |
| T4+T45 缺失 | ? | 进一步损失 |

**若 T4 缺失时 R² 仍高**，说明 RSSM 从其他传感器推断出了 T4 信息。
