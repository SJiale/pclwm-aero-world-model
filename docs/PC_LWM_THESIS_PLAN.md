# PC-LWM 硕士论文叙事与证据规划（2026-11-05）

> 工作题目：《面向航空发动机动态预测与控制的物理约束潜在世界模型研究》  
> 当前仅规划论文结构，不将任何待实现的控制应用表述为已有结果。

## 论文的研究故事

1. **工程需求**：高保真组件级发动机模型在反复候选动作推演/优化中可能成本较高；需量化后才能确认该瓶颈。
2. **模型研究问题**：现有 RSSM 是否能通过真实物理状态锚定与多跨度变化约束提高长期自主推演表现？快慢动态分离是否真有额外收益？
3. **方法**：构建 PC-RSSM；只有证据支持时纳入 DT-PC-RSSM/物理功率一致性等模块，形成 PC-LWM。
4. **工程验证**：明确定义控制动作后，将世界模型置于同一受约束 MPC 框架，相对 PI/EEC、GRU/RSSM 代理 MPC 检验性能/约束/效率。
5. **工程失配**：在隐藏参数改变后，研究后验状态更新和模型参数校正能否恢复控制能力。
6. **边界**：目前属于 AGTF30-e 仿真研究原型，不是真机闭环数字孪生，也没有形式化安全保证。

## 候选论文贡献与创新性风险

- **候选贡献 A（模型）**：物理锚定潜状态与多跨度动力学监督对低维发动机数据的适配。**注意**：PSG-JEPA 已有相关思想，不能声称首次提出静态/动态锚定；需要用因果先验递推、发动机动态目标与公平性能证明工程方法价值。
- **候选贡献 B（动力学）**：在有证据时，物理时间尺度引导的动态更新与快慢表征分工。**注意**：SF-RSSM 等已有双速分支；PSVA 本身不是双速动力学，PGTT 必须对比固定 K 与等容量模型。
- **候选贡献 C（应用与适应）**：不同发动机隐藏参数下的可信 MPC 代理与有限数据在线校正。**注意**：MPC、BC 初始化、Actor–Critic 并非新算法；实际贡献需要来自一致动作接口、鲁棒控制性能与适应证据。

## 论文必须保留的失败/替代结果

- 旧固定 K 双时间尺度在单次实验中未表现出稳定收益，不预先改写成成功机制。
- T4 可由 T45 简单回归得到高精度，不以单传感器重构作为世界模型核心创新证明。
- E0–E3 单种子改善为初步结果；多种子结果若不稳定，要如实报告。
- MPC 若只是达到传统控制性能，仍有研究价值，但不能声称控制性能优越；可报告代价、约束/算力权衡。
- DT 失败或 Actor–Critic 未做，不妨碍保留有证据的主线 PC-RSSM/MPC 研究。
