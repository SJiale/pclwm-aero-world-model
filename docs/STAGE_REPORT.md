# PC-LWM 阶段技术报告：双时间尺度 RSSM 与传感器失效重构

> 日期：2026-11-04
> 仓库：https://github.com/SJiale/pclwm-aero-world-model
> **核心原则：严格区分实验事实与研究假设，未经验证的提升不作为结论**

---

## 摘要

本阶段研究两条独立技术线：

| 线 | 内容 | 主要结论 |
|---|---|---|
| **A** | 双时间尺度 RSSM（DT-RSSM）| ❌ 固定 K 无提升，K 越大越差 |
| **B** | Mask-aware 传感器失效重构 | ✅ 在线重构有效，但 Mask-GRU 优于 Mask-RSSM |

**最重要的发现**：传感器失效重构中，模型主要依靠**历史外推**，其他正常传感器的**即时反馈增益仅 3–10%**。

## 2. 时间尺度探索性分析

### 2.1 三类时间尺度必须分离

| 类别 | 定义 | 本轮能否分离 |
|---|---|---|
| (a) 输入激励 | PLA/Alt/MN 波形 | ✅ 已知 |
| (b) 闭环控制响应 | EEC 调节动态 | ❌ 混在观测里 |
| (c) 系统内部动力学 | 物理惯性 | ❌ 混在观测里 |

**观测是闭环系统的输出，无法直接分离 (b) 和 (c)。**

### 2.2 为什么不能归因（三条实证）

**证据 1：Wfact 是 EEC 输出，不是自由变量**
- `|Wfact − Wfdmd|` 的 99 分位 = 0.027 lb/s，占均值 **4.0%**
- 执行器跟踪极快 → Wfact 的平滑性可能来自控制律

**证据 2：N2 快速跟随 Wf**
- N2 相对 Wf 的最优滞后 = **0.63 s**
- 转子由 EEC 快速调油驱动，"N2 上升快"≠"转子惯性小"

**证据 3：时间尺度随激励变化**

| 通道 | step 轨迹 ACF | ramp 轨迹 ACF | 差异 |
|---|---|---|---|
| Wfact | 7.88 s | 9.55 s | 18% |
| N2int | 7.98 s | 9.45 s | 16% |
| T4 | 7.67 s | 9.29 s | 18% |

**同一通道在不同激励下差 16–18% → 反映的是激励而非固有属性。**

### 2.3 表观时间尺度（探索性）

| 通道 | ACF 衰减中位 | 上升时间 | f90 |
|---|---|---|---|
| Wfact_lb_s | 8.6 s | **2.31 s** | 0.112 Hz |
| N2int | 8.3 s | **1.05 s** | 0.112 Hz |
| T4 | 7.7 s | 1.68 s | 0.149 Hz |
| T45 | 7.7 s | 1.78 s | 0.149 Hz |
| P36 | 8.7 s | 2.26 s | 0.112 Hz |

**ACF 比值仅 1.1×，上升时间比值 2.2× —— 时间尺度分离很弱。**

**且与原始假设相反**：转子最快（1.05 s），燃油最慢（2.31 s）。

### 2.4 谨慎结论

**✅ 可以说**：表观层面未见明显时间尺度分离（ACF 比值 1.1×）

**❌ 不能说**：
- "N2int 是固有快动态"
- "Wfact 是固有慢动态"
- "1.05 s 是物理惯性常数"

## 3. DT-RSSM 架构

### 3.1 数学形式

**快状态**（每步）：
$$h_t^{\text{fast}} = \text{GRU}_{\text{fast}}\left([z_{t-1}, a_t, h_{t-1}^{\text{slow}}], h_{t-1}^{\text{fast}}\right)$$

**慢状态**（每 K 步）：
$$h_t^{\text{slow}} = \begin{cases}
\text{GRU}_{\text{slow}}\left([h_t^{\text{fast}}, z_{t-1}], h_{t-1}^{\text{slow}}\right) & t \bmod K = 0 \\
h_{t-1}^{\text{slow}} & \text{otherwise}
\end{cases}$$

**随机潜状态**（保留原 RSSM）：
$$p(z_t \mid h_t^{\text{fast}}, h_t^{\text{slow}}, z_{t-1}), \quad q(z_t \mid \cdot, \text{Enc}(o_t))$$

**解码**：$\hat{o}_t = \text{Dec}([h_t^{\text{fast}}, h_t^{\text{slow}}, z_t])$

### 3.2 参数量匹配（关键对照设计）

**问题**：DT-RSSM 双 GRU 导致参数量高 58%，无法区分容量收益与结构收益。

**方案**：加宽基线 RSSM 至参数量对齐。

| 模型 | 配置 | 参数量 | 相对 DT |
|---|---|---|---|
| RSSM-d128 | deter=128, hidden=128 | 939,909 | 0.63× |
| **RSSM-wide** | **deter=136, hidden=256** | **1,486,141** | **1.001×** |
| DT-K1/4/8 | fast=96, slow=96 | 1,484,773 | 1.00× |
| DT-K4-matched | fast=48, slow=48 | 1,069,045 | 0.72× |

### 3.3 单元测试（24 项全部通过）

| 组别 | 关键验证 |
|---|---|
| 状态维度 | h_fast(96)/h_slow(96)/z(32×32)/feat(1216) |
| **慢状态周期** | **K=4 时只在 t=0,4,8 变化（逐步验证）** |
| **先验递推** | **encoder 只调 T=32 次（无未来泄漏）** |
| 梯度 | 26 个张量全部有梯度 |
| 训练稳定性 | 100 步 loss 2.135→1.316 |
| 推理模式 | gumbel 可复现、argmax 确定性 |

### 4.4 关键判读

2. DT-K1 vs RSSM-wide 短期性能几乎相同（0.0944 vs 0.0932）

- 说明单种子结果不稳定
- 连续递推方差 >> 分段递推

### 4.5 ⚠️ 已修复的严重 bug

**连续递推误差计算存在 NumPy 广播错误：**

```python
# 错误：pred [1,C] - gt [1,1,C] -> [1,1,C]
# 取 [0] 得 [1,C]，mean(axis=1) 得 [C]（逐通道），再取 [-1] 变成最后一通道误差
E = np.stack(errs, 0)                 # [n, 1, C]
ps = np.sqrt((E**2).mean(axis=1))     # [n, C]  ← 错误！
final = ps[-1] / ref                  # 变成"最后一个通道"
```

**后果**：连续递推误差被低估 **7 倍**（RSSM-d128 记录 0.0128，实际 0.0984）。

**修复后**：
```python
diff = (pred - gt[:, 0]).numpy()[0]   # 显式 [C]
assert diff.shape == (C_O,)
E = np.stack(errs, 0)                  # [n, C]
ps = np.sqrt((E**2).mean(axis=1))      # [n] 标量
```

**所有正式结果已用修复后代码重算（`results_v2_fixed.json`）。**
**`results_v2.json` 的 `long_continuous` 字段已废弃。**

## 5. Mask-aware 传感器失效重构

### 5.1 任务定义

**不是开环预测，而是在线部分观测状态估计。**

| 时段 | T4 | 其他 4 个传感器 | PLA/Alt/MN |
|---|---|---|---|
| 0–20 s | ✅ 正常 | ✅ 正常 | ✅ 可用 |
| ≥20 s | ❌ 失效 | ✅ **正常** | ✅ 可用 |

**目标**：用 T4 历史 + 其他传感器 + 控制输入，持续估计 T4。

### 5.2 数学形式

**掩码**：$m_t \in \{0,1\}^C$，$m_{t,i}=1$ 表示通道 $i$ 有效。

**观测填充**（归一化空间 $x_{\text{fill}}=0$ 即训练集均值）：
$$\tilde{x}_t = m_t \odot x_t + (1-m_t) \odot x_{\text{fill}}$$

**Mask-aware Encoder**：
$$e_t = \text{Enc}([\tilde{x}_t, m_t])$$

**后验**（只用有效信息）：
$$z_t \sim q(z_t \mid h_t, e_t)$$

**关键**：$m_t$ 显式告知"该通道丢失"，而非把填充值当真实测量。

### 5.3 训练时缺失增强

| 模式 | 概率 | 参数 |
|---|---|---|
| 完整 | 0.20 | 全部有效 |
| 固定缺失 | 0.25 | T4 全程失效 |
| 随机缺失 | 0.25 | 每步随机丢 30%（至少留 1）|
| 突发缺失 | 0.30 | T4 随机起点连续缺失 8–32 步 |

### 5.4 单元测试与信息隔离审计

**27 项单元测试全部通过**，其中信息隔离 3 项：

| 测试 | 结果 |
|---|---|
| 故障后 T4 观测改 999 | 输出不变（max diff = **0.00e+00**）|
| 故障前 T4 历史改 999 | 输出变化（max diff = 0.0264）|
| 缺失 vs 完整观测 | 输出不同（max diff = 0.0313）|

**13 项在线推理审计全部通过**：

| 审计项 | 结果 |
|---|---|
| 故障后 T4 +500 污染 | max diff = **0.00e+00** |
| **故障后 T4 设为 1e6** | max diff = **0.00e+00** |
| 故障前 T4 +500 污染 | max diff = 0.0227（有影响）|
| 污染 Wfact → 影响 T4 重构 | diff = 0.0243 ✅ |
| 污染 N2int → 影响 T4 重构 | diff = 0.0247 ✅ |
| 污染 T45 → 影响 T4 重构 | diff = 0.0245 ✅ |
| 污染 P36 → 影响 T4 重构 | diff = 0.0271 ✅ |
| 第 1 次 encoder（纯历史）T4 mask | = 1 ✅ |
| 预测段 T4 mask | 96.4% 为 0 ✅ |
| 其他通道 mask | 始终 = 1 ✅ |

**结论：故障后 T4 真值绝不进入模型；4 个正常传感器全部参与状态更新。**

这是**重要的负面结论**：Mask 机制的价值被高估了。
不是"模型不会用其他传感器"，而是"其他传感器本身信息不足"。

## 7. 已验证结论 vs 失败假设

### ✅ 已验证的实验事实

1. 原始 RSSM-d128 短期预测最好（test_id 0.0898）
2. 固定 K 的 DT-RSSM 短期性能随 K 单调退化（K1 0.0944 → K8 0.1162）
3. 同容量对照 RSSM-wide（0.0932）与 DT-K1（0.0944）短期几乎相同
4. T4/T45 是所有模型中误差最大的通道（0.12，是 P36 的 1.8 倍）
5. **Mask-GRU 在全部 8 个（场景×划分）组合中都优于 Mask-RSSM**
6. Mask-GRU 重构相对 persistence 改善 81–94%
7. **在线 vs 纯外推的差距仅 3–10%**
8. 信息隔离验证 13/13 通过（含 1e6 极端污染测试）
9. Mask-GRU 参数量为 Mask-RSSM 的 1/4，推理快 5.4 倍

### ❌ 失败的研究假设

1. **"双时间尺度分离能提升短期预测"** —— 数据不支持，K 越大越差
2. **"DT 的结构优势来自时间尺度机制"** —— 同容量对照短期性能相近
3. **"K=4 是合理的工程初值"** —— K=4 明显差于 K=1
4. **"Mask-RSSM 的潜状态机制有助于缺失数据重构"** —— 全部场景都输给 Mask-GRU
5. **"其他传感器能大幅提升 T4 重构"** —— 仅贡献 3–10%

### ⚠️ 不能得出的结论

1. **不能说"DT-RSSM 优于原始 RSSM"** —— 短期上原始 RSSM 更好
2. **不能把单种子结果当作统计显著结论**
3. **不能说"连续递推 0.0128"** —— 那是广播 bug 的产物
4. **不能把分段递推的改善归因于时间尺度**
5. **不能把故障重构与故障检测混为一谈**

## 8. 实验局限

1. **单随机种子训练**（seed=0），评估时 gumbel 重复 3 次
2. **测试集小**：test_id 仅 2 条轨迹，test_ood 3 条
3. **KL 项仍失效**（free_bits=1.0 导致全维度 KL 低于阈值），本轮不修以保持可比
4. **60 epoch 可能不足**让慢状态学好
5. **K 只测 1/4/8**，未做细粒度搜索
6. **故障检测未实现**（本轮只做重构）
7. **只测 T4 单通道失效**，未测多通道同时失效
8. **未测 T4 偏置/卡死**等软故障
9. **连续递推方差大**，稳定性原因未分析
10. **时间尺度分析未做开环实验**，无法分离控制与本体

## 9. 后续算法创新建议

### 9.1 优先级排序

| 优先级 | 方向 | 依据 |
|---|---|---|
| **P0** | **多种子重复** | 当前所有结论都是单种子 |
| **P0** | **温度通道专项改进** | T4/T45 误差是其他通道 1.8 倍 |
| **P1** | **信息论分析：传感器对 T4 的互信息** | 解释为何在线增益仅 3–10% |
| **P1** | **连续递推稳定性分析** | 方差过大，需查根因 |
| **P2** | **可学习时间尺度门控** | 固定 K 失败，但思路未必错误 |
| **P2** | **故障检测框架** | 本轮未做 |
| **P3** | DT + Mask 联合 | 需先确认 Mask-RSSM 有优势（当前没有）|

### 9.2 关于 DT + Mask 联合的判断

**用户要求：先判断 Mask-RSSM 是否可靠，再考虑与 DT 结合。**

**当前结论：Mask-RSSM 不如 Mask-GRU，因此不建议立即做 DT+Mask 联合。**

**更好的方向**：
- 分析 Mask-RSSM 失败原因（后验更新 vs 缺失数据训练的冲突）
- 或直接在 Mask-GRU 上做改进（它已经是更好的基线）

### 9.3 关于"双时间尺度"的重新定位

固定 K 失败，但保留可能性：

| 方案 | 说明 |
|---|---|
| 可学习门控 | 用网络学习更新频率，而非固定 K |
| 多分辨率 | 在特征层做多尺度池化，而非状态层 |
| **暂缓** | 先解决 P0 问题（多种子、温度通道）|
